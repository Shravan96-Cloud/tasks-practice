Day 1 — Linux Filesystem Practice
Objective: Practice directory management, file creation, navigation, copying, moving, and file inspection.

Repository: tasks-practice

Complete these tasks inside your day-1 folder.
1. Create a project directory named web-server with separate folders for the application, configuration, backups, and scripts.
2. Create a configuration file named app.conf inside the configuration folder.
3. Add the following settings to the configuration file:
   - Application name: web-server
   - Port: 8080
   - Environment: development
4. Create a file named deploy.sh inside the scripts folder.
5. Navigate between different directories using relative and absolute paths.
6. Display your current working directory and your Linux username.
7. Copy the configuration file into the backup folder while keeping the original.
8. Rename deploy.sh to start-server.sh.
9. Create a backup-info.txt file explaining which file was backed up.
10. Display the contents of app.conf and verify the final directory structure.
Completion criteria: All files must be in the correct locations, the configuration must contain the required settings, and the original configuration file must remain intact.
