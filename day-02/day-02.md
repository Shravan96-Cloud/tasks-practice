# Day 2 — Linux Logs and Git Practice

Objective: Practice log inspection, searching, file management, safe deletion, and Git fundamentals.

Complete these tasks inside your `day-2` folder.

1. Create a project named `server-monitoring` with separate folders for logs, configuration, and backups.
2. Create a `server.log` file containing at least 10 realistic server log entries.
3. Include successful events, a warning about high memory usage, and an error involving a database connection.
4. Display the first three lines of the log file.
5. Display the last three lines of the log file.
6. Search the log file for entries containing the word `Error`.
7. Find all regular files inside the project directory.
8. Find the file named `server.log` within the project directory.
9. Copy the log file into the backup folder and verify that both copies exist.
10. Create a temporary file and delete it using a command that asks for confirmation.
11. Create a `report.txt` file documenting the total number of log entries, the warning found, and the error found.
12. Check the Git status of your repository.
13. Stage your Day 2 work and create a commit with a meaningful message.
14. Inspect your latest commit and verify that your changes are recorded.

Completion criteria: Your log file must contain at least 10 entries, your backup must exist, your report must be accurate, the temporary file must be deleted, and your Git commit must succeed.
